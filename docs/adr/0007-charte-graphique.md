# ADR 0007 — Charte graphique

**Contexte.** Application institutionnelle, utilisateurs peu technophiles, WCAG 2.1 AA (ENF-12).
Options discutées : bleu foncé `#2D3C8F`, violet, vert drapeau.

**Décision.** Primaire **Bleu institutionnel `#2D3C8F`** (contraste 9,75:1 sur blanc) ; accent **or « sceau »**
réservé à la signature et à la vérification ; violet `#6D3FC0` réservé au statut « Prêt à signer » ;
vert/rouge sémantiques inspirés du drapeau. Inter (UI), Source Serif 4 (PDF), JetBrains Mono (références).
Détail : [`docs/design-system.md`](../design-system.md).

**Conséquences.**
+ Lecture « administration » immédiate ; l'or donne un repère visuel fort à l'acte officiel.
− Le violet n'est pas la couleur de marque.
